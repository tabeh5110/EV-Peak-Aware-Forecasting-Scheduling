# Reproduction Guide

## Overview

This repository provides the implementation for:

"Peak-Aware EV Charging-Station Load Forecasting and Constrained Scheduling Using an Adaptive Hybrid Ensemble"

The workflow includes:

1. Data preprocessing
2. Hourly load generation
3. Leakage-free feature engineering
4. Forecasting model training
5. Peak-risk calibration
6. Prediction interval estimation
7. Statistical validation
8. Forecast-informed scheduling
